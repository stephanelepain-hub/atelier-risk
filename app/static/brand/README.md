# CPLT brand files

`logo.svg` is the CPLT header mark (canonical file from cplt.tech, `brand/cplt-mark.svg`). The only change is
`color="#FFFFFF"` on the root element, so the C takes the white header text colour; the gold dot is unchanged.
`favicon.svg` is the CPLT icon (`brand/cplt-icon.svg`), unchanged.

These files are CPLT's brand, not covered by the EUPL licence of the code. If you run your own copy of Atelier, remove
this folder: the app then shows no logo.
